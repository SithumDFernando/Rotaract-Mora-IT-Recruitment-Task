# Rotaract Club of University of Moratuwa | Official IT Team Recruitment

## OFFICIAL IT TEAM RECRUITMENT
### Mini Web Development Task — Time Slot Booking Web Application

**Task Period:** 26 July 2026 – 1 August 2026

---

## 1. Task

Build a small web application that allows a user to book an available time slot. A time slot that is already booked must not be available to another user.

This is a small individual task designed to review basic frontend, backend, database, GitHub, and deployment skills.

---

## 2. Minimum Requirements

- One simple page or dashboard — no login, signup, or admin dashboard.
- A booking form with name, date, time slot, category, and a short note.
- Display available and already-booked time slots clearly.
- Prevent duplicate or overlapping bookings.
- Store bookings using a backend and a shared database or hosted data service.
- Add at least five demo booking records to the deployed database.
- Create a clean, usable, and responsive interface.
- Use any technology stack.

---

## 3. Optional Features

These are not required, but they may receive additional marks:

- Filter bookings by date, time, category, or priority.
- Simple calendar view.
- Edit or delete a booking.

---

## 4. Submission

- Public GitHub repository with the complete source code.
- Working deployed link using Vercel or any other suitable platform.
- Short README containing setup instructions and the technology stack used.
